Biotage Flash Plotter

Overlay Biotage Isolera flash-chromatography runs — best-effort column detection, see note below.
Heads up: there's no single confirmed Biotage export format — column headers in "File > Export" or the Isolera Run Report can vary by instrument and software version. This tool guesses which columns are volume / UV / %B by matching keywords in the header row, and shows you its guess under each upload so you can sanity-check it. If it guesses wrong, type the exact column name into the override box for that sample — that always wins over the guess.
