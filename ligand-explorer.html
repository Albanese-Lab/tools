What sits next to M3L?

This pulls every PDB entry containing the chemical component you specify, computes a distance-based sphere around each occurrence, and tallies the residue chemistry found inside it — contact distances, an approximate axial orientation relative to the ligand's functional tip, and amino acid category. Everything runs client-side against the live RCSB APIs. Each sphere can also be exported as a standalone motif, ready to hand to RFdiffusion-style backbone scaffolding.

Scaffold-ready export

Extracts just the sphere — the ligand plus every contact residue's full atoms, original chain IDs and residue numbers intact — as a minimal PDB, alongside a suggested RFdiffusion-style contig and a residue manifest. This is scaffolding input, not a ready-to-run job file: check the gap lengths and your local tool's exact input schema (RFdiffusion3 in particular uses a JSON/YAML spec that's still evolving) before submitting.

PLIP interaction validation

PLIP protonates the structure and detects typed, geometry-checked interactions — hydrogen bonds with a real donor–H…acceptor angle (not just a heavy-atom distance, which is all the ring-angle cation-π classification and contact table above can do from coordinates alone), plus π-stacking, π-cation, salt bridges, halogen bonds, water bridges, and metal coordination — interaction types this tool doesn't compute itself. It has no public API (unlike Foldseek above), so it can't run in your browser: this generates a ready-to-run local command/snippet instead, same pattern as the Folddisco panel.

Mutation-scan export (alanine scanning)

One job per contact residue, mutated to alanine, plus a wild-type reference — formatted for both Rosetta (resfiles) and Boltz-2 affinity (YAML). The tool auto-detects whether the ligand sits on a peptide/protein chain or as a standalone ligand and builds each accordingly. Nothing here runs the prediction itself; these are job inputs to submit on your own compute.

Structural neighbor search (Foldseek)

Submits this whole structure to the public Foldseek search server to find structurally similar folds — including AlphaFold DB predictions that aren't annotated with this ligand at all, but may share the pocket geometry. This is a live public API call made directly from your browser; it may fail on CORS or rate limits depending on the server's current config — if so, download the structure and run foldseek easy-search locally or on your cluster instead.

QM cluster export

Capped side-chain fragments for DFT single-point energies — real crystallographic heavy-atom coordinates, with hydrogens added by standard local geometry (sp3 ~109.5°, sp2/aromatic ~120°, 1.09 Å C–H) since X-ray structures don't resolve them. Each job optimizes only the added hydrogens (heavy atoms held fixed) to clean up that approximate placement, then reports energy.

Data: RCSB PDB Search API & RCSB file server, queried live in your browser. Legacy .pdb coordinate files are used, so entries only available in mmCIF (very large assemblies) are skipped. Contact geometry is a first-pass computational triage tool — verify anything load-bearing by inspecting the structure directly.
