ITC Thermogram Plotter

Overlay raw isothermal titration calorimetry injection-heat traces.

File format: upload the 2-column raw injection-heat CSV export (time in minutes, DP in µcal/s) — the same "raw data" export produced by the instrument software (e.g. NanoAnalyze / Origin). This tool does not read the instrument's native .itc binary file directly — export to CSV first.
All parsing happens locally in your browser — files are never uploaded anywhere. Nothing is saved between visits; reload the page to start fresh.
